# Synthetic onboarding example

`efl_tutorial_synthetic.csv` is the Stage VII-E1 first-run dataset for Empirical Finance Lab. It is **fully synthetic**: it does not contain CRSP, Compustat, vendor, issuer, investor, or other proprietary/research data, and it does not represent a real security or a real market event.

The file is deterministic and generated by `generate_tutorial_dataset.py`. Do not hand-edit the CSV; regenerate it from the script if the tutorial contract is intentionally changed.

## Integrity anchor

- Rows: **180**
- Columns: `date`, `security_return`, `benchmark_return`
- Return units: **decimal**
- Event date used by the tutorial: **2025-07-31**
- SHA-256: `e3b4d1004ee960106ac17618e680f5af4fb1c5286ff5d58234bb903bc321797e`

Under `efl_tutorial_specification.json`, the frozen Python scientific authority must recover:

- AR(-1) = **+1.000%**
- AR(0) = **+3.000%**
- AR(+1) = **-1.000%**
- CAR[-1,+1] = **+3.000%**

These values are an onboarding known answer, not evidence about any real asset, event, trading strategy, or causal effect.

## Regenerate

From repository root:

```bash
python examples/generate_tutorial_dataset.py
python tools/check_stage7_e1_onboarding_gate.py
```

The Stage VII-E1 gate byte-compares the committed CSV with the deterministic generator and then runs the **existing frozen Python core** against the committed tutorial specification. It fails if the file, specification, documentation contract, or known numerical result drifts.

For the browser walkthrough, see [`docs/quickstart.md`](../docs/quickstart.md).

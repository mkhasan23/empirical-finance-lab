# Tests

Stage IV tests the production numerical core *against* the authoritative fixtures in `validation/`.

Golden/reference outputs are never generated by the production implementation under test.

Coverage layers currently include:

- all 24 Stage III authoritative fixtures;
- unit tests for event-time/validation behavior;
- known-answer AR/CAR and model coefficients;
- independent classical-inference reference;
- exact and seeded permutation references;
- hand-enumerable placebo reference;
- robustness matrix reference;
- 15 failure/runtime contracts;
- reproducibility/hash sensitivity;
- row-order, unit, metadata, robustness, and RNG invariance;
- end-to-end analysis integration.

Authoritative command:

```bash
pytest -q
```

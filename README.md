# Empirical Finance Lab

**Audit-first research software for credible, transparent, and reproducible empirical finance.**

> **Stage III / pre-alpha:** This repository skeleton contains the frozen scientific/technical specifications and authoritative validation corpus. It does **not** yet contain a production event-study engine and must not be represented as a validated research release.

## Scientific workflow

**Compute -> Audit -> Stress-test -> Interpret -> Reproduce**

The first module will be the **Audit-First Event Study Analyzer** for one security and one event using daily returns. Its purpose is not merely to calculate AR/CAR, but to expose data validity, model assumptions, specification sensitivity, placebo evidence, inference assumptions, and reproducibility metadata.

## Stage III contents

- frozen Stage I scientific specification;
- frozen Stage II architecture specification;
- Stage III validation-corpus specification;
- machine-readable analysis/audit/export schemas;
- authoritative known-answer fixtures;
- independent inference references;
- hand-enumerable placebo fixture;
- robustness fixture;
- 15 explicit failure-mode fixtures;
- corpus-integrity manifest and CI check.

## Important governance rule

Reference outputs in `validation/` are **not generated by the future production numerical engine**. A change to a golden/reference answer requires an independent derivation and an explicit numerical-impact classification.

## Citation

A `CITATION.cff` is included now so citation metadata is part of the project from inception. The current `0.0.0` state is **not a validated scholarly release**. Formal citations should use a later version-specific DOI after release validation.
